# 2.0.0：一鍵安全清理與五種整理工具

這次改版重做安全清理頁面，讓程式先判斷有明確用途的舊快取，並把需要使用者決定的資料放進獨立工具。總覽與資料樹沿用既有功能。

## 使用時會看到的改變

整個 App 的頁首、圖表、設定、掃描流程與清理說明已重新檢查。刪除空泛標題、設計自述及同屏重複，並修正報告時間、容量估計、Terminal 停止方式與刪除範圍等容易誤導的文字。

也修正切換報告時，即時容量可能短暫沿用上一個磁碟數值的問題；現在容量數字會與讀取位置一起核對。

- **一鍵安全清理**：重新掃描後，直接清除符合條件的一天前程式快取、三十天前套件下載快取與舊診斷。舊診斷無法重建，畫面會說明；也可先查看或加入保留清單。
- **五種人工整理**：專案建置資料、安裝檔、大型與舊檔、重複檔、程式與關聯資料。全部先由使用者選取、確認，再移到垃圾桶。
- **重複檔完整內容比對**：先篩大小與片段，再完整比對，每組指定保留檔。執行前再次比對，保留檔有變動就跳過副本。
- **理由、檢視與保留清單**：查看內容與容量，從結果保留位置，也能自行新增檔案或資料夾。
- **停止與紀錄**：記錄實際成功、失敗、垃圾桶位置與容量；紀錄寫入失敗時仍保留當次畫面的實際成果。垃圾桶移入量與系統可用空間分開顯示。
- **清理前重驗**：使用中的程式、共用資料、環境、模型與保留設定會參與判斷；跨視窗清理後，舊掃描結果不能繼續執行。

舊版六級規則保留在「進階規則」，包含既有外接磁碟與遠端掛載的處理方式。新版一鍵清理不會因此自動擴張到這些位置。

## 研究與開源說明

研究了 Mole 的用途分流與最後移除檢查、Mac Sai 的掃描／選取／執行架構，以及 CleanMyMac 的主操作、詳細管理與保留清單。已安裝程式的靜態研究有明確限制，沒有宣稱還原商業安全資料庫。

詳細文件：[清理邏輯](../cleanup-logic.md)、[研究對照](../cleanup-research.md)、[維護與擴充](../cleanup-development.md)。文件列出清理位置、條件、排除、停止與還原方式，以及後續新增規則的測試要求。

## 驗證與限制

完整原始碼驗證共四十四階段，涵蓋既有掃描、中文路徑、資料樹索引、清理政策、暫存資料實際移除及原生正式建構。新增清理案例的數量與結果見附錄。真機介面已驗證唯讀預覽、中文重複檔、內容檢視、確認後取消、程式與資料分列，以及保留位置選擇；沒有在真實使用者資料上執行清理。

程式關聯資料讀取不完整時會保留，尚未涵蓋所有專用卸載器、共享服務與自訂資料位置。專案套件中的私人修改仍需自行保存；手動整理資料夾前應停止相關工作。
