# MacStorageLens 1.8.0 · Build 35

本版針對現有「總覽、資料樹、安全清理」進行本機最佳化。Scanner 維持 2.5.4，最低 macOS 14，SwiftPM 套件與 Markdown 報告格式保持相容，沒有新增相依套件。

- **資料樹導航**：解析時建立有容量上限的目錄位置索引，清單與 Sunburst 可直接定位到子樹；索引位置先驗證，無效時回退原讀法。兩份本機報告各抽樣 8 個目錄，結果完全一致，讀取中位數分別從 78 ms／94 ms 降到約 2 ms／0.3 ms。這是抽樣導航時間，不代表整碟掃描速度。
- **原生檔案列舉**：修正 Foundation 略過 `._` AppleDouble 與 `/var` 路徑別名導致分類或驗證對不上的問題；保留套件、symlink、跨檔案系統及資源分支的安全邊界。
- **本機保護清單**：若已有 Mole，會讀取其 `~/.config/mole/whitelist`，不執行腳本；模型、Playwright 瀏覽器、已登錄 Python 與共用 Android 執行環境受到保護。標準快取、容器與狀態也會依執行中的 App 排除。
- **執行前重驗證**：舊候選同樣套用最新保護設定；掃描後新增保護也能阻止刪除。既有保護設定讀取失敗時暫停可執行清理，容量批次讀取失敗時逐項重查，只接受完整成功的容量並列出受限目錄。
- **Homebrew**：預覽與執行均採官方預設 `cleanup` 保留期限，移除原先執行時額外加入的 `--prune=all`。
- **關於**：記錄目前與 GPT‑6.1 SOL 在 Codex 本機協作，保留早期 GPT‑5.6 Pro 的歷史協作說明。

更新後會重建呈現及清理索引，既有容量報告仍可讀取。舊版已寫成問號的報告仍需重新掃描；本版不會自動清除任何使用者資料。個人路徑、保護清單與掃描報告不包含在公開來源中。

詳見 [本機驗證與設計範圍](../LOCAL_OPTIMIZATION.md) 與 [第三方來源說明](../../THIRD_PARTY_NOTICES.md)。延續原始碼 ZIP 發布方式，解壓後執行 `scripts/建立並啟動.command` 在本機建立 App。
